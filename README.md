# 님 게임 PWA (iPhone / Android)

## GitHub Pages에 올리기
1. 이 ZIP의 파일을 모두 압축 해제합니다.
2. GitHub 저장소 `alexjoeyyunjoon/nim-game`의 Code 탭에서 Add file → Upload files를 누릅니다.
3. 압축을 푼 파일을 저장소 루트에 업로드하고 Commit changes를 누릅니다. 기존 파일은 같은 이름으로 교체합니다.
4. Settings → Pages에서 `main` 브랜치와 `/(root)`를 선택합니다.

## iPhone에 설치하기
1. iPhone에서 Safari로 `https://alexjoeyyunjoon.github.io/nim-game/`를 엽니다.
2. Safari의 공유 버튼(네모에서 위쪽 화살표)을 누릅니다.
3. 메뉴에서 `홈 화면에 추가`를 선택합니다.
4. 표시 이름을 확인하고 `추가`를 누릅니다.

참고: iPhone에서는 Chrome 대신 Safari로 홈 화면에 추가하는 방법을 권장합니다. iOS 버전에 따라 메뉴 이름이 조금 다를 수 있습니다.

## Android에 설치하기
Chrome에서 사이트를 연 다음 메뉴(⋮)에서 `앱 설치` 또는 `홈 화면에 추가`를 선택합니다.
